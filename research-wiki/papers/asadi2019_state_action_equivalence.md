# Model-Based Reinforcement Learning Exploiting State-Action Equivalence

## One-line thesis
Equivalence-aware confidence sets (C-UCRL) with ApproxEquivalence for estimating unknown equivalence structure online — the unknown-structure case supported empirically, without theory.

## Key Results
- Closest prior art on estimating equivalence classes online; consumed for sample-efficiency, never for secondary-objective routing; no guarantees in the estimated-structure regime.

## Relevance to This Project
Round-3 sweep: precedent and caveat for online-estimated equivalence — supports the conservative, verifiable-core-first evidence rule.
